# Fonts for generated images

Roboto Condensed (weights 500 and 800), static TTF, downloaded from Google
Fonts (`fonts.gstatic.com`, v31) on 2026-11-14. Licensed under the SIL Open
Font License 1.1 (https://openfontlicense.org).

`next/og` (`ImageResponse`) only reads TTF, OTF or WOFF, so the Open Graph
image loads these files; the pages themselves use `next/font/google`.
